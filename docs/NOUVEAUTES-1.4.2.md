# Mire 1.4.2

Icônes officielles Google Material, au format vectoriel :

- Reprendre : Play Arrow, triangle de lecture.
- Rouvrir : Restore, retour autour d’une horloge.
- Supprimer : Delete Outline, corbeille.

Les cartes de l’accueil, l’historique et les actions du résumé partagent les mêmes ressources. Les libellés, les confirmations et les données restent inchangés. Les anciens dessins manuels de reprise et de suppression ont été retirés. Les SVG source et la licence Apache 2.0 sont inclus dans artwork/material-icons.
