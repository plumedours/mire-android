## 1.4.3 — À publier / Not yet published

### Français

- Correctif ciblant une fermeture de l’APK release sur Galaxy S21 : désactivation de l’optimisation R8 après une erreur d’accès à une classe Kotlin dans AndroidX Startup.
- Numéro de version Android porté à `9`, sans changement du format des données.
- Démarrage de l’APK signée à confirmer sur appareil avant publication comme version stable.

### English

- Addresses a release APK startup crash reported on a Galaxy S21: R8 optimisation is disabled following a Kotlin class access error in AndroidX Startup.
- Android version code increased to `9`, with no data format changes.
- Signed APK startup still requires device confirmation before this version is labelled stable.
