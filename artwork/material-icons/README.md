# Material action icons

Official Google Material Icons, Apache License 2.0 (see LICENSE).

- play_arrow: resume an active session.
- restore: reopen a completed session without discarding its previous arrows.
- delete_outline: request deletion, with confirmation.

Original SVGs are retained in this directory. Android vector drawables in app/src/main/res/drawable/ic_material_*.xml preserve the visible SVG paths verbatim. Transparent background paths are omitted. Material 3 applies the button content colour at runtime. No icon font, bitmap conversion or additional dependency is used.
